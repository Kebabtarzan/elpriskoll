# Elkollen

En responsiv elpris-dashboard för Sverige.

## Starta
Öppna `index.html` direkt i webbläsaren. Om webbläsaren blockerar API-anrop från lokala filer, kör en lokal server i mappen, exempelvis `python -m http.server 8080`, och öppna `http://localhost:8080`.

## Publicera gratis
Ladda upp de tre filerna till GitHub Pages, Netlify eller Cloudflare Pages. Ingen byggprocess krävs.

## Data
Priser hämtas från Elpriset just nu API. Spotpris visas med valbar moms. Elnät, energiskatt och elhandlarens påslag ingår inte.
